Pipe span natural frequency

First four bending modes of a straight pipe span between supports, the quick check behind span-length decisions in piping vibration work.

Defaults: 6" Sch 40 carbon steel, water-filled. For gas service set contents density to the gas density (or 0).

ModeλLFrequency (Hz)CPM

The formulas

fi = ((λiL)² / 2πL²) · √(EI / m)
I = π(Do⁴ − Di⁴)/64    m = pipe + contents + insulation mass per metre

λL comes from each support condition's frequency equation: nπ for pinned–pinned, cosh·cos = 1 for fixed–fixed and free–free, cosh·cos = −1 for a cantilever, tan = tanh for fixed–pinned.

Real pipe supports are neither perfectly pinned nor perfectly fixed, so the true first mode usually sits between the pinned–pinned and fixed–fixed results. That band is a useful sanity check against FEA or a field measurement. Heavy valves or flanges in the span, bends, and support flexibility all pull the frequency down; for those, use FEA.
